# 🧪 Lab Assignment 02 – Conditional Statements in Python

## 📘 Instructions

1. Write each program in a separate Python file.
2. Use `if`, `if-else`, or `if-elif-else` statements wherever appropriate.
3. Accept input from the user.
4. Display clear and meaningful output.
5. Test your programs with different input values.

---

## 1 Largest of Three Numbers

**Problem:**

Write a Python program that accepts three numbers from the user and displays the **largest number**.

**Hint:**

Use the `and` logical operator to compare multiple conditions.

### Sample Output

```text
Enter First Number: 45
Enter Second Number: 82
Enter Third Number: 36

Largest Number = 82
```

## 2 Electricity Bill Calculator

**Problem:**

Write a Python program to calculate the electricity bill based on the number of units consumed.

### Tariff

| Units Consumed  | Rate per Unit |
| --------------- | ------------- |
| Up to 100 units | ₹5            |
| 101 – 200 units | ₹7            |
| Above 200 units | ₹10           |

### Formula

```
Bill = Units × Rate
```

### Sample Output

```text
Enter Units Consumed: 150

Rate per Unit = ₹7
Total Bill = ₹1050
```
