# Python Exercise: Student Activity Management Using Sets

**Objective:** Practise creating sets and using Union, Intersection and Difference operations.

### Problem Statement

A college conducts two extracurricular activities: Cricket and Football.

The following students have registered:

```python
cricket = {"Amit", "Rahul", "Sara", "John"}
football = {"Sara", "John", "Priya", "David"}
```

Write a Python program to perform the following tasks:

1. Display the students registered for Cricket.
2. Display the students registered for Football.
3. Find all unique students registered for either activity (Union).
4. Find students registered for both activities (Intersection).
5. Find students who registered for Cricket but not Football (Difference).
6. Find students who registered for Football but not Cricket (Difference).
7. Display the total number of unique students registered across both activities.

### Expected Results

| Task | Expected Result |
|---|---|
| Union | 6 students |
| Intersection | Sara, John |
| Cricket - Football | Amit, Rahul |
| Football - Cricket | Priya, David |
| Total unique students | 6 |
